A modern, responsive outdoor lifestyle and e-commerce website designed to showcase travel essentials, camping accessories and everyday adventure products.

## Project Overview

Terra & Tales is a nature-inspired outdoor lifestyle website featuring a clean, modern and minimal design.

The website focuses on presenting outdoor products, membership plans and newsletter subscription features through a user-friendly interface.

## Features

- Modern and responsive homepage
- Light cream and pastel colour theme
- Responsive navigation bar
- Attractive hero section
- About section
- Product collection with 9 products
- Product category filtering
- Interactive wishlist buttons
- Three membership plans
- Detailed membership registration form
- Newsletter subscription form
- Form validation using JavaScript
- Mobile-friendly layout
- Custom footer design

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, Grid, Flexbox and responsive design
- **JavaScript** – Navigation, product filtering, wishlist and form interactions

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Explore the website and its interactive features.
